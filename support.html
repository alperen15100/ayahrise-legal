AyahRise Support

For bug reports, Quran text/source concerns, audio issues, accessibility feedback or Google Play support:

Email: ecrincrypto@gmail.com

Before contacting support

  • Make sure you are using the latest AyahRise version available to you.
  • For audio problems, check your internet connection or re-download the relevant surah audio.
  • For reminder problems, check Android notification permission and battery/background restrictions.
  • If reporting a Quran text, translation or attribution issue, include the surah and ayah number and the selected translation.

Data recovery

If you previously exported an AyahRise JSON backup, use the in-app import option to restore supported local data. Keep your own backup copies in a safe location.
